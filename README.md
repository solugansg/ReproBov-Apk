## Instrucciones de Instalacion

1. **Descargar el archivo:** Toca el enlace de descarga arriba desde tu dispositivo Android.
2. **Abrir el archivo:** Una vez completada la descarga, pulsa sobre la notificacion o buscalo en la carpeta de Descargas.
3. **Permisos de instalacion:** Si Android muestra una advertencia de seguridad, selecciona Ajustes y activa Permitir desde esta fuente.
4. **Instalar o Actualizar:** Presiona Instalar (o Actualizar). Tus datos locales en SQLite permaneceran intactos.
